# 步骤1：动态碳势曲线生成和COMSOL测试

## 功能说明

这个程序实现了以下功能：

1. **从 `load_carburizing_data` 提取强渗实验数据**
   - 自动筛选 `process_type = 'carb_only'` 的实验
   - 共7组强渗实验数据（DS03, DS04, DS05, DS15等）

2. **动态生成碳势曲线**
   - 根据工艺参数计算表面碳势随时间的变化
   - 支持脉冲渗碳工艺（升压-保压-降压循环）
   - 输出为 `carb.txt` 文件

3. **COMSOL仿真测试**
   - 自动加载 `carbon_content_3.mph` 模型
   - 读取 `carb.txt` 设定表面碳势边界条件
   - 运行仿真并提取碳浓度分布
   - 对比实验数据和模拟结果

## 使用方法

### 1. 准备工作

确保以下文件在当前目录：
- `load_carburizing_data.m` - 实验数据加载函数
- `carbon_content_3.mph` - COMSOL模型文件
- `step1_generate_carb_and_test.m` - 本程序

### 2. 运行程序

在MATLAB命令窗口输入：

```matlab
step1_generate_carb_and_test()
```

### 3. 交互过程

程序会依次执行：

1. 加载并显示强渗实验数据
2. 设置碳势曲线参数（当前使用默认值）
3. 生成碳势曲线并保存到 `carb.txt`
4. 可视化碳势曲线（完整曲线 + 前3个周期细节）
5. 询问是否运行COMSOL测试
   - 输入 `y` 运行COMSOL仿真
   - 输入 `n` 跳过仿真

### 4. 输出结果

程序会生成以下内容：

- **carb.txt** - 碳势曲线数据文件（时间-碳势）
- **碳势曲线图** - 完整曲线和局部细节
- **对比图**（如果运行COMSOL）- 实验vs模拟数据对比

## 参数说明

### 碳势曲线参数

当前使用的默认参数：

```matlab
beta = 1.4;           % 碳势系数
tau = 10;             % 衰减时间常数（周期数）
C_final = 0.011;      % 最终碳势（1.1%）
tau_rise = 35;        % 升压时间常数（秒）
tau_fall = 40;        % 降压时间常数（秒）
```

### COMSOL参数

```matlab
D0 = 5e-11;          % 扩散系数 (m²/s)
k_m = 0.1;           % 传质系数
```

### 工艺参数（固定）

```matlab
Q_C2H2 = 10;         % 乙炔流量 (L/min)
Q_N2 = 8;            % 氮气流量 (L/min)
P_high = 3;          % 高压 (kPa)
P_low = 0.5;         % 低压 (kPa)
T_rise = 140;        % 升压时间 (s)
T_hold = 30;         % 保压时间 (s)
T_fall = 90;         % 降压时间 (s)
```

## carb.txt 文件格式

```
时间(秒)  碳势(小数)
0.000000 0.005234
1.000000 0.005456
2.000000 0.005680
...
```

- 每行两列，空格分隔
- 时间：从0开始，步长1秒
- 碳势：小数形式（例如 0.011 = 1.1%）

## COMSOL模型要求

模型应包含：

1. **插值函数**：`C_surface_func`（程序会自动创建）
   - 数据源：`carb.txt` 文件
   - 参数：时间 `t`

2. **全局参数**：
   - `D0` - 扩散系数
   - `k_m` - 传质系数

3. **边界条件**：
   - 表面碳势使用 `C_surface_func(t)`

4. **研究**：
   - Study: `std1`
   - 时间相关求解：`time`

## 注意事项

1. **MATLAB版本**：要求 MATLAB 2023b
2. **COMSOL连接**：运行前确保COMSOL Server已启动
3. **文件路径**：所有文件应在同一目录
4. **单位转换**：
   - 实验数据：碳浓度为百分比 (%)，深度为 mm
   - COMSOL模型：碳浓度为小数，深度为 m
   - carb.txt：碳浓度为小数

## 故障排除

### COMSOL连接失败

```
错误: Java exception occurred: com.comsol.util.exceptions.FlException
```

**解决方法**：
1. 启动 COMSOL Server
2. 在MATLAB中运行 `mphstart`
3. 检查COMSOL许可证

### 模型文件未找到

```
错误: 无法加载文件: carbon_content_3.mph
```

**解决方法**：
1. 确认模型文件在当前目录
2. 使用完整路径指定模型文件

### carb.txt无法创建

```
错误: 无法创建文件: carb.txt
```

**解决方法**：
1. 检查当前目录写入权限
2. 关闭可能打开carb.txt的程序
